## Option A — API (fastest, needs a BscScan API key)

The same BscScan/Etherscan API key used for mainnet works on the v2 API
for chain 97. The key is never stored — pass it only as an environment
variable for the one command:

```bash
cd ~/workspace/agent-mint-launch
BSCSCAN_API_KEY=<your BscScan API key> node scripts/submit-bscscan.mjs
```

It submits the Solidity Standard JSON input (`verification/standard-json.json`)
and polls `checkverifystatus` until it passes. Result is saved to
`verification/bscscan-result.json`.
