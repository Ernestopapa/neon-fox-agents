Mint rules

    
The rules, in plain words

    

      
Total supply
3,333. Set in the contract; there will never be more.

      
Free phase
The first 1,000 mints are free for Binance Agent ID holders — 1 per wallet, 0 BNB, gas only. One free mint per wallet, ever.

      
Paid phase
Opens only after all 1,000 free mints are claimed. Agent ID holders only — same gate as the free mint. Price is exactly 0.00007 BNB per mint (about $0.05), maximum 5 per transaction, exact payment required.

      
The gate
For both the free and the paid mint, the contract checks the Agent ID registry: balanceOf(wallet) > 0. The free mint also requires that the wallet has not already used its free mint. Otherwise the call reverts.

      
Royalties
5% on secondary sales, set in the contract via ERC-2981. royaltyInfo(tokenId, salePrice) returns 5% of the sale price to the owner — for example, 0.05 BNB on a 1 BNB resale. supportsInterface returns true for ERC-2981, so marketplaces that honour ERC-2981 can read it. Royalties are paid by the seller’s marketplace on resale, never on mint.

      
Owner powers
Supply, the free allocation and the paid price are set in the verified contract code. The owner can withdraw BNB collected from paid mints, and receives the 5% ERC-2981 royalty on secondary sales. That is the extent of it — read the verified source before you mint.

      
What is not promised
No roadmap utility, no return, no price promise. NFOX is a collectible. See Transparency below.

FAQ

    
Questions

    

      

        Do I need a Binance Agent ID to mint?
        
Yes — for both the free mint and the paid mint. The contract checks the Agent ID registry for your wallet and reverts if there is no Agent ID. Use the eligibility checker above to see exactly what your wallet can do right now.

      

    

    

      

        How do I check if I qualify without connecting a wallet?
        
Paste your wallet address into the checker at the top of this page. It makes read-only calls to the contract and the registry — no connection, no signature — and reports your Agent ID, free-mint status and NFOX balance.

      

    

    

      

        What does “free” mean here?
        
The NFT itself costs 0 BNB during the free phase. You still pay the network gas for the transaction, as with any on-chain mint. One free mint per wallet, ever.

      

    

    

      

        What happens when the 1,000 free mints are gone?
        
The free phase closes and paid minting opens automatically at exactly 0.00007 BNB per mint (about $0.05), up to 5 per transaction, until the 3,333 supply is reached. Paid minting is Agent ID holders only, same as the free mint. The live counts in the hero show where things stand.

      

    

    

      

        Can my AI agent mint for me?
        
Yes — that is the main route. Copy the prompt in section 02, or give your agent the llms.txt on this page. The prompt makes the agent run the eligibility checks first, preview the exact call and value, and wait for your confirmation before executing.

      

    

    

      

        Is there a royalty on resales?
        
Yes — 5%, set in the contract using ERC-2981. When a fox is resold on a marketplace that honours ERC-2981, royaltyInfo tells it to pay 5% of the sale price to the owner — for example, 0.05 BNB on a 1 BNB resale. The contract reports supportsInterface as true for ERC-2981. There is no royalty on minting itself, and marketplaces that ignore ERC-2981 will not pay it.

      

    

    

      

        Why does my wallet show “No Agent ID” on this site?
        
The contract checks the real Binance Agent ID registry on mainnet (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F). If the wallet you checked holds no Agent ID there, the checker reports “No Agent ID” and the mint reverts — check the exact wallet that holds your Agent ID.
